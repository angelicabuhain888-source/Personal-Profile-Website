CC107 Activity 4 — Personal Portfolio Website

Files:
- index.html: semantic HTML and all four required sections
- style.css: separate CSS with Grid, Flexbox, hover effects, and media queries
- script.js: separate, commented JavaScript interactions

Run:
Keep all three files in one folder. Open index.html in a browser or use VS Code Live Server.

Personalize before submitting:
1. Replace "Your Name" and "YN" with your name and initials.
2. Update the biography and introduction.
3. Replace your.email@example.com with your real email.
4. Update the GitHub link.
5. Adjust sample projects to match your own work.
6. The profile graphic is a placeholder icon; you may replace it with your own photo and alt text.

Submit all three code files in a PUBLIC GitHub repository. For bonus points, enable GitHub Pages and submit the HTTPS live URL.
Font Awesome icons load from a CDN and require an internet connection.
